Project Documentation ---- Survey Feedback Analyzer

Project Overview   
        
This project is an analysis tool built in Python.It stores survey feedback,cleans the text and extract simple insights such as word counts,average rating,longest feedback and the unique words used.

Tools used                                                                                                                                                                   
*IDLE(Python)

Steps Followed                                                                                                                                                          
*Started the program with preloaded dictionary of 10 feedbacks.                                                                                                       
*Took additional feedbacks from user and appended them.                                                                                                               
*Cleaned the feedback text(removed punctuations,extra spaces and converted into lower case).                                                                          
*Created the function count_word_in_feedbacks(word) to count the feedbacks containing a word.                                                                         
*Displayed the cleaned data,average rating,longest feedbacks and unique words.                                                                                        
*Sorted feedbacks by rating from highest to lowest.

Files included                                                                                                                                                          
1.Survey Feedback Analyzer.py - Python code                                                                                                                           
2.README.md - Project Description.

How to use                                                                                                                                                              
*Open Survey Feedback Analyzer.py in a Python IDLE or Jupyter Notebook.                                                                                               
*Run the program and enter the number of additional feedbacks.                                                                                                        
*Enter the Name, Feedback and Rating (1–5) for each new feedback.                                                                                                     
*View the word counts, cleaned data, average rating, longest feedback, unique words and sorted feedbacks in the output.
